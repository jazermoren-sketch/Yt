# Arabic Quiz Bot V1 🇲🇦

بوت Quiz عربي بالكامل لـ Discord.

## التشغيل
1. ثبت Node.js 18 أو أحدث.
2. نفذ:
   npm install
3. انسخ `.env.example` إلى `.env`.
4. ضع `DISCORD_TOKEN` و `CLIENT_ID`.
5. شغل:
   npm start

## الأوامر
- `/quiz` بدء لعبة
- `/profile` ملفك الشخصي
- `/leaderboard` الترتيب
- `/daily` سؤال اليوم
- `/admin-question add` إضافة سؤال
- `/admin-question list` عرض الأسئلة
- `/admin-question delete` حذف سؤال

## المرحلة الثانية: نظام التلميحات 💡
- كل إجابة صحيحة تمنح تلميحات حسب الصعوبة: سهل +1، متوسط +2، صعب +3.
- حذف جواب خاطئ: 1 تلميح.
- معلومة: 2 تلميحات.
- تلميح قوي: 3 تلميحات.
- أول حرف: 4 تلميحات.
- كل نوع من التلميحات يستعمل مرة واحدة في السؤال.

## المرحلة الرابعة: Webhook Presentation System 🎭
- طبقة Webhook لإظهار رسائل المسابقة بهوية Quiz Master.
- هويات مختلفة للسؤال والنتائج والفائز.
- `src/utils/webhook_manager.js` مسؤول عن الإرسال عبر Webhook.
- `config/webhooks.json` للتحكم في المظهر.
- إذا لم يتم إعداد Webhook، يرجع النظام تلقائياً للإرسال العادي عبر البوت.
- المتغيرات الاختيارية:
  - `QUIZ_WEBHOOK_ID`
  - `QUIZ_WEBHOOK_TOKEN`


## المرحلة الخامسة: Professional Question Engine 🧠
- بنك أسئلة مستقل في `data/question_bank.json`.
- تصنيفات وصعوبات منظمة.
- منع تكرار الأسئلة داخل نفس المسابقة.
- اختيار عشوائي ذكي حسب التصنيف والصعوبة.
- Validation للأسئلة قبل إضافتها.
- إحصائيات بنك الأسئلة.
- دعم Import/Export لبنك الأسئلة.
- كل سؤال يدعم: `question`, `answers`, `correct`, `category`, `difficulty`, `explanation`, `hint`, `smartHint`.
